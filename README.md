## Hi, I'm Serdar

Computer Engineering student at Düzce University. I work with Python on machine learning, LLM evaluation and automation.

### Projects

**[review-bench](https://github.com/serdarakbay/review-bench)**: Benchmark measuring how well LLMs review code written by another (or the same) LLM. Claude, Gemini and Qwen as reviewers; 16k logged reviews with manual adjudication.

**[Kaggle Playground S6E10](https://github.com/serdarakbay/kaggle-s6e10-airline-satisfaction)**: Airline satisfaction prediction. Feature engineering, LightGBM / XGBoost / CatBoost and a logistic regression stack with nested CV. Private AUC 0.96238, 178th of 3748 (top 5%).

**[Marswalk Planner](https://github.com/serdarakbay/marswalk-planner)** (NASA Space Apps Challenge 2026, Istanbul, top 10, team of 5): Layered Mars surface map and EVA route planner. I built the sun/Earth position data from JPL Horizons, the EVA time window logic and the astronaut HUD.

**[hype-clipper](https://github.com/serdarakbay/hype-clipper)** (Codex x TwitchCon hackathon, solo): Detects hype moments in Twitch chat and automatically clips them.

**[LumenCity](https://github.com/egejpg/LumenCity)** (CODE>ENERGY hackathon, team project): Smart city platform for light pollution and lighting energy waste. I built the formal complaint flow with facial recognition, worked on role-based access control and the user interface.
